Admin

This page is a dashboard, on purpose: it shows you what the stack is doing and lets you add a user. Everything that changes the stack — passwords, removals, isolation repair, quotas, sources, mail, backups, updates, lockouts, parked files, the request queue — lives in the admin tools on the server (bookstack.sh over SSH, on the tailnet once Lock SSH has been run). Secrets and root actions stay on the box rather than behind a browser session.
